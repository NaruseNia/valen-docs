# キーワード

## 言語キーワード

レキサーが専用トークンとして無条件に消費し、識別子として**使えません**。

| キーワード | 用途 |
|---|---|
| `fn` | 関数宣言 |
| `let` | 変数バインディング |
| `mut` | ミュータブル変数 / ミュータブルフィールド / ミュータブル self |
| `self` | メソッドのインスタンスレシーバ |
| `return` | 関数からの早期リターン |
| `if` | 条件式 |
| `else` | `if` の代替ブランチ |
| `match` | パターンマッチ式 |
| `class` | クラス宣言 |
| `data` | データクラス修飾子（`data class`）。レキサーは `data` をすべての位置で完全なキーワード（`Data` トークン）として扱い、コンテキストキーワードではない |
| `enum` | Enum (ADT) 宣言 |
| `trait` | Trait 宣言 |
| `impl` | Trait 実装 / 固有実装ブロック |
| `pub` | パブリック可視性修飾子 |
| `internal` | 同一モジュール可視性（デフォルト） |
| `private` | 宣言プライベート可視性 |
| `open` | クラスまたはメソッドのオーバーライドを許可 |
| `override` | 親クラスメソッドのオーバーライド |
| `abstract` | 抽象クラスまたはメソッド（本体なし） |
| `sealed` | 閉じた階層 — `sealed class`、`sealed trait` |
| `package` | パッケージ宣言（ファイルヘッダ） |
| `import` | 型をスコープにインポート |
| `for` | for ループ（`for x in collection`） |
| `in` | `for` でのイテレータバインディング、反変の変性アノテーション |
| `while` | while ループ |
| `loop` | 無限ループ（`break` で脱出） |
| `break` | ループを脱出（オプションで値を伴う） |
| `continue` | 次のループイテレーションにスキップ |
| `as` | Import エイリアス（`import ... as`）、型キャスト（`expr as Type`） |
| `safe` | Java 例外キャッチブロック（`safe { }`、`safe expr`、`safe?`） |
| `unsafe` | 安全性保証のバイパス（`unsafe { }`、`unsafe fn`） |
| `ref` | ミュータブル参照作成（`ref mut` として使用） |
| `inline` | インライン関数修飾子（本体が呼び出し側で展開） |
| `reified` | reified 型パラメータ（イレイジャーを通じて具体型を保持）。レキサーは `reified` をすべての位置で完全なキーワード（`Reified` トークン）として扱い、コンテキストキーワードではない |
| `annotation` | アノテーションクラス宣言 |
| `typealias` | 型エイリアス（`typealias UserId = Int`） |
| `newtype` | Newtype ラッパー（`newtype EntityId = Int`） |
| `type` | Trait 内の関連型（`type Item;`） |
| `true` | 真偽値リテラル |
| `false` | 真偽値リテラル |
| `out` | 共変の変性アノテーション |

## 予約キーワード

将来の使用のために予約されたキーワードです。レキサーが専用トークンを生成しますが、パーサーは現在受け付けません。識別子として**使えません**。

| キーワード | 予定されている機能 |
|---|---|
| `suspend` | コルーチン / 構造化並行性 |
| `async` | 非同期計算 |
| `await` | 非同期結果の取得 |
| `yield` | ジェネレータ / コルーチンの yield |

## JVM 予約語

これらの Java キーワードは Valen では使いませんが、混乱やバイトコードの衝突を防ぐため識別子として**禁止**されています。

| キーワード | 備考 |
|---|---|
| `static` | Valen は `static` メンバーの代わりに関連関数（`self` レシーバなし）を使用 |
| `void` | Valen は `Unit` を使用 |
| `this` | Valen は `self` を使用 |
| `super` | JVM 互換性のために予約。Valen は現在、親クラスディスパッチのための `super` を公開していない |
| `null` | Valen に null リテラルはない。JVM null は `T?` (Nullable) と Java 連携を通じて扱う |
| `throw` | Valen は `Result<T, E>` と `safe {}` でエラー処理 |
| `try` | Valen は `safe {}` ブロックを使用 |
| `catch` | Valen は `safe {}` ブロックを使用 |
| `finally` | Valen のエラーモデルでは該当なし |
| `extends` | Valen はクラス継承に `:` を使用 |
| `implements` | Valen は trait 実装に `impl` を使用 |

::: tip
`new` は Valen の**キーワードではなく**、識別子として使えます。レキサーは `new` を認識しますが `Ident("new")` にマッピングします。コンストラクタ呼び出しは `new` なしの `ClassName(args)` 構文を使います。
:::

## 演算子と記号

### 算術演算子

| 演算子 | 説明 |
|----------|------|
| `+` | 加算 |
| `-` | 減算 / 単項否定 |
| `*` | 乗算 / 参照外し |
| `/` | 除算 |
| `%` | 剰余 |

### 比較演算子

| 演算子 | 説明 |
|----------|------|
| `==` | 構造的等値（`.equals()`） |
| `!=` | 構造的非等値 |
| `===` | 参照同一性（JVM 参照チェック） |
| `!==` | 参照非同一性 |
| `<` | 小なり |
| `<=` | 以下 |
| `>` | 大なり |
| `>=` | 以上 |

### 論理演算子

| 演算子 | 説明 |
|----------|------|
| `&&` | 論理 AND（短絡評価） |
| `\|\|` | 論理 OR（短絡評価） |
| `!` | 論理 NOT |

### ビット演算子

| 演算子 | 説明 |
|----------|------|
| `&` | ビット AND |
| `\|` | ビット OR |
| `^` | ビット XOR |
| `<<` | 左シフト |
| `>>` | 右シフト |

### 代入演算子

| 演算子 | 説明 |
|----------|------|
| `=` | 代入 |
| `+=` | 加算代入 |
| `-=` | 減算代入 |
| `*=` | 乗算代入 |
| `/=` | 除算代入 |
| `%=` | 剰余代入 |

### 範囲演算子

| 演算子 | 説明 |
|----------|------|
| `..` | 排他的範囲 |
| `..=` | 包含的範囲 |

### パイプラインと矢印

| 演算子 | 説明 |
|----------|------|
| `\|>` | パイプライン演算子 |
| `->` | 戻り型矢印 |
| `=>` | match アーム矢印 |

### 記号

| 記号 | 説明 |
|-------|------|
| `?` | Try 演算子 — `Err`/`None` を早期リターンで伝播。`Option<T>` と `Result<T, E>` にのみ対応 |
| `@` | アノテーション記号。アノテーション構文（`@AnnotationName`）用に予約。現在ユーザーが書くことはできず、識別子の前に `@` を使うとパースエラー |
| `#` | 属性記号。マップリテラル（`#{}`）で使用 |
| `_` | ワイルドカードパターン / プレースホルダ。専用トークンであり、識別子ではない |

### デリミタ

| トークン | 説明 |
|-------|------|
| `(` `)` | 丸括弧（関数呼び出し、グループ化） |
| `{` `}` | 波括弧（ブロック、class/enum/trait の本体） |
| `[` `]` | 角括弧（リストリテラル、インデックス） |

### セパレータ

| トークン | 説明 |
|-------|------|
| `,` | 要素セパレータ |
| `;` | 文ターミネータ |
| `:` | 型注釈セパレータ |
| `::` | パスセパレータ |
| `.` | フィールドアクセス / メソッド呼び出し |

### レキサーの優先順位

3文字トークン（`===`、`!==`、`..=`）は2文字トークン（`==`、`!=`、`..`、`->`、`=>`、`<=`、`>=`、`<<`、`>>`、`&&`、`||`、`|>`、`::`、`+=`、`-=`、`*=`、`/=`、`%=`）より先にマッチし、2文字トークンは1文字トークンより先にマッチします。最長一致規則に従います。
